# CnCTDRAMapEditor/Properties/

## Responsibility
Assembly metadata and project resources/settings for the `CnC TDRA Map Editor` WinForms executable. Compact folder — no logic.

## Design
- `AssemblyInfo.cs` — standard attributes: `AssemblyTitle`/`AssemblyProduct` = "CnC TDRA Map Editor", `AssemblyCompany` = "Electronic Arts Inc.", `© 2020` copyright, `ComVisible(false)`, typelib GUID `397cef00-8930-4ec8-b15f-f7cf7193fb22`, `AssemblyVersion`/`AssemblyFileVersion` = `1.0.0.0`.
- `Resources.resx` + `Resources.Designer.cs` — strongly-typed resource accessor (`Properties.Resources`, e.g. `UI_CustomMissionPreviewDefault` used by `Dialogs/SteamDialog` for the solo-mission preview banner); the 818 KB `.resx` is dominated by embedded UI images.
- `Settings.settings` / `Settings.Designer.cs` — user-scoped application settings accessed as `Properties.Settings.Default`, notably `ToolDialogPosition` (persisted window location written on every `OnMove` by every `Tools/Dialogs/*` dialog).

## Flow
Read-only consumers: dialogs and tools read `Settings.Default.*` and call `.Save()`; resource literals are referenced by type name throughout the editor.

## Integration
Referenced by `MainForm`, `Program`, `Dialogs/*`, `Tools/*` and `Tools/Dialogs/*`; generated by Visual Studio (`.Designer.cs` files are regenerated, do not hand-edit).
