# CnCTDRAMapEditor/Steamworks.NET/types/SteamHTTP/

## Responsibility
Autogenerated handle structs for the Skynet HTTP client API: `HTTPRequestHandle` (one in-flight HTTP request issued through Steam's proxying) and `HTTPCookieContainerHandle` (a reusable cookie jar attached to requests).

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): primitive-backed structs with `Invalid` sentinel, equality/comparison operators, and explicit conversions; one struct per file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
`ISteamHTTP.CreateHTTPRequest` → `HTTPRequestHandle`; completion arrives via `HTTPRequestCompleted_t` callback through `CallbackDispatcher`; `SendHTTPRequest` results and headers are then read back by handle. Cookie containers persist across requests.

## Integration
Consumed by `autogen/isteamhttp.cs` (and the gameserver variant); see `types/codemap.md` for the common generated-handle template. Unused by the editor directly — vendored for SDK completeness; do not restyle.
