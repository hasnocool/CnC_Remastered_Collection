# CnCTDRAMapEditor/Steamworks.NET/types/Steam_api_common/

## Responsibility
Autogenerated handle structs shared by the API-initialization surface: `HSteamPipe` and `HSteamUser`. In the SDK these come from `steam_api_common.h` and identify, respectively, a communication pipe to the Steamworks API and a user (global or game server) context on that pipe; the generated C# mirrors are the plumbing tokens handed back by `SteamAPI_Init`/`SteamAPI_GetHSteamUser` style calls.

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): `int`-backed structs with `Invalid` sentinel, equality/comparison operators, and explicit conversions — one struct per file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
Every generated interface method takes `PtrToStringUTF8`-style marshaled args but internally routes through `SteamAPI_GetHSteamPipe`/`GetHSteamUser`-sourced values; these handles are created/destroyed by `Steam.cs` init/shutdown and threaded through `NativeMethods` flat calls.

## Integration
Consumed by `autogen/isteamclient.cs` and `NativeMethods.cs`; see `types/codemap.md` for the common generated-handle template. Vendored — do not restyle.
