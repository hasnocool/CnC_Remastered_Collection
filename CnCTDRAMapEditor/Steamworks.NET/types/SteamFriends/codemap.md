# CnCTDRAMapEditor/Steamworks.NET/types/SteamFriends/

## Responsibility
Autogenerated value type for the friends/community interface: `FriendsGroupID_t`, the opaque handle for a user-defined friends group ("favorites", custom tags) inside the Friends list.

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): primitive-backed struct with `Invalid` sentinel, equality/comparison operators, explicit conversions; a single file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
Obtained from `ISteamFriends` group-enumeration calls and passed back when reading or membership-managing friends groups; the editor never constructs these itself.

## Integration
Consumed by `autogen/isteamfriends.cs` signatures; see `types/codemap.md` for the common generated-handle template. Vendored — do not restyle.
