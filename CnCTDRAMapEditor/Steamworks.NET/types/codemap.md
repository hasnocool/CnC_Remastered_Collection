# CnCTDRAMapEditor/Steamworks.NET/types/

## Responsibility
Autogenerated, per-Steam-interface value types: one subdirectory per `ISteam*` functional area in the Steamworks SDK (18 groups), each containing the handle/ID structs that interface's flat header declares (`*_t`, `H*`, `Steam*IDs`). Subdirectory `codemap.md` files describe each group; the shared mechanical template is the same everywhere.

## Design
- **Strongly typed opaque handles:** every struct is a generated wrapper over a primitive (`ulong`/`int`/`uint`) with field name matching the SDK (`m_UGCQueryHandle`, `m_AppId`, …), an `Invalid`/`Invalid.m_<field>` sentinel, `IEquatable<T>` + `IComparable<T>`, `==`/`!=` operators, explicit `ulong`↔struct conversions, and `ToString`. This prevents accidentally mixing IDs of different kinds at call sites marshaling into the flat API.
- **Whole type in one file:** each struct is a standalone `.cs` file under its owning interface's folder (e.g. `SteamUGC/UGCQueryHandle_t.cs`), enabling the generator to diff per-header.
- Platform-neutral: all files are guarded by `#if !DISABLESTEAMWORKS` and free of platform branches.

## Flow
Structs flow between editor code (`Utility/SteamworksUGC`) and the generated `NativeMethods` flat functions purely as marshaled values — constructed from API-call return values, compared against `Invalid`, or passed to `Steam.UGC`/`Steam.RemoteStorage` calls; nothing in this tree ever calls into Steam itself.

## Integration
Referenced by `Steamworks.NET/autogen/isteam*.cs` signatures and callback structs, by `Utility/SteamworksUGC.cs` (Workshop publish/query) and `Dialogs/SteamDialog` (e.g. checking `PublishedFileId_t.Invalid.m_PublishedFileId`). Regenerated whenever Steamworks.NET is version-bumped — do not restyle; group subdirectories: MatchmakingTypes, Steam_api_common, SteamClient, SteamClientPublic, SteamController, SteamFriends, SteamHTMLSurface, SteamHTTP, SteamInput, SteamInventory, SteamMatchmaking, SteamNetworking, SteamRemoteStorage, SteamScreenshots, SteamTypes, SteamUGC, SteamUnifiedMessages, SteamUserStats.
