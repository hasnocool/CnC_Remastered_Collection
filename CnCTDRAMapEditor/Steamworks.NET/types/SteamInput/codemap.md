# CnCTDRAMapEditor/Steamworks.NET/types/SteamInput/

## Responsibility
Autogenerated handle structs for the modern Steam Input API (successor of the legacy controller API): `InputHandle_t` (a connected controller device) and the action tokens `InputActionSetHandle_t`, `InputAnalogActionHandle_t`, `InputDigitalActionHandle_t` resolved from an Input Action Manifest.

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): `ulong`-backed structs with `Invalid` sentinel, `IEquatable`/`IComparable`, explicit conversions; one struct per file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
At init `ISteamInput` loads the action-set manifest and converts named sets/actions into these handles; per-frame polling of digital/analog state takes the device handle plus the matching action handle; device connectivity arrives via callbacks (`InputConnect/disconnected_t`).

## Integration
Consumed by `autogen/isteaminput.cs`; see `types/codemap.md` for the common generated-handle template. Unused by the editor — vendored for SDK completeness; do not restyle.
