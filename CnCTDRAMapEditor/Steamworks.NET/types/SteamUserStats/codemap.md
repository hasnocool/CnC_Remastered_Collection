# CnCTDRAMapEditor/Steamworks.NET/types/SteamUserStats/

## Responsibility
Autogenerated handle types for the stats/achievements/leaderboard API: `SteamLeaderboard_t` (an opened leaderboard), and `SteamLeaderboardEntries_t` (the downloaded batch of leaderboard entries from a `DownloadLeaderboardEntries` call).

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): `ulong`-backed structs with `Invalid` sentinel, equality/comparison operators, and explicit conversions; one struct per file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
`ISteamUserStats.FindOrCreateLeaderboard` yields `SteamLeaderboard_t`; entry downloads return `SteamLeaderboardEntries_t`, consumed inside the subsequent `LeaderboardScoresDownloaded_t` callback routed by `CallbackDispatcher`.

## Integration
Consumed by `autogen/isteamuserstats.cs` and `isteamgameserverstats.cs`; see `types/codemap.md` for the common generated-handle template. Unused by the editor — vendored for SDK completeness; do not restyle.
