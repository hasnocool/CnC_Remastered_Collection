# CnCTDRAMapEditor/Steamworks.NET/types/SteamUGC/

## Responsibility
Autogenerated handle structs for the Workshop (UGC) API — the most editor-relevant group: `UGCQueryHandle_t` (an in-flight query built via `CreateQueryUser`/`CreateQueryAllUGCRequest` that later yields workshop item pages) and `UGCUpdateHandle_t` (an in-progress item update created by `StartItemUpdate` for the staged publish of a map).

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): `ulong`-backed structs with all-ones `Invalid` sentinel (e.g. `0xffffffffffffffff`), `IEquatable`/`IComparable`, `==`/`!=`, explicit `ulong` conversions; one struct per file, `#if !DISABLESTEAMWORKS` guarded. The physical `PublishedFileId_t`/`UGC` file handles that carry the resulting IDs live in the `SteamRemoteStorage` group.

## Flow
Publish path (`Utility/SteamworksUGC`): `CreateItem` → `StartItemUpdate` → `UGCUpdateHandle_t` (`SetItemTitle`/`Description`/`Tags`/`Content`/`Preview` calls) → `SubmitItemUpdate` → `SubmitItemUpdateResult_t` callback releases the handle. Query path: `SendQueryUGCRequest` → `UGCQueryCompleted_t` → results read per `UGCQueryHandle_t` then released.

## Integration
Consumed by `autogen/isteamugc.cs`/`isteamgameserverugc.cs`, `Utility/SteamworksUGC.cs`, and indirectly `Dialogs/SteamDialog`; see `types/codemap.md` for the common generated-handle template. Vendored — do not restyle.
