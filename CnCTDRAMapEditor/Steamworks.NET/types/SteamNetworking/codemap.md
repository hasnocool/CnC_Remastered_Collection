# CnCTDRAMapEditor/Steamworks.NET/types/SteamNetworking/

## Responsibility
Autogenerated handle structs for the legacy (pre-sockets-API) P2P networking interface: `SNetListenSocket_t` (a listening socket accept group created with `CreateListenSocket`) and `SNetSocket_t` (one established connection — P2P or direct-to-server — from `Connect`/`CreateConnectionPair`/`Accept`).

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): `uint`-backed structs with `Invalid` sentinel, equality/comparison operators, and explicit conversions; one struct per file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
Listen sockets yield connection sockets through `[SNet]ConnectionState_t` callbacks; data flows via `SendDataOnSocket`/`RetrieveDataFromSocket`, and both handle kinds are closed with `CloseListenSocket`/`CloseSNetSocket`. Nothing here touches the newer `ISteamNetworkingSockets` system.

## Integration
Consumed by `autogen/isteamnetworking.cs` and `isteamgameservernetworking.cs`; see `types/codemap.md` for the common generated-handle template. Unused by the editor — vendored for SDK completeness; do not restyle.
