# CnCTDRAMapEditor/Steamworks.NET/types/SteamClient/

## Responsibility
Autogenerated function-pointer/delegate structs declaring the typeable surface of the private client API (`steam_api.h` beyond the flat functions): `SteamAPI_CheckCallbackRegistered_t`, `SteamAPI_PostAPIResultInProcess_t`, and `SteamAPIWarningMessageHook_t`. They represent the SDK's exported function-pointer contracts — checking callback registration, receiving in-process API results, and the optional warning-message hook the app can install to see `SteamAPI` diagnostics.

## Design
Generated delegate/struct declarations (© 2013–2019 Riley Labrecque, MIT) with `[UnmanagedFunctionPointer]`-style interop conformance so `Steam.cs`/`CallbackDispatcher` can assign managed handlers over the native entry points; one declaration per file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
At init, `Steam.cs` may install a `SteamAPIWarningMessageHook_t` to surface Steam client warnings; in-process results and callback-registration checks are exercised whenever `CallbackDispatcher` validates that a callback struct is registered before dispatching managed delegates.

## Integration
Wired exclusively by the hand-written `Steamworks.NET/Steam.cs`, `CallbackDispatcher.cs`, and `autogen/NativeMethods.cs`; see `types/codemap.md` for the common generated type template. Vendored — do not restyle.
