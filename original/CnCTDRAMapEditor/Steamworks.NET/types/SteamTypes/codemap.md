# CnCTDRAMapEditor/Steamworks.NET/types/SteamTypes/

## Responsibility
Autogenerated SDK-wide scalar ID types shared across every interface (heritage: `steamtypes.h`): `AppId_t`, `DepotId_t`, `AccountID_t`, `ManifestId_t`, `PartyBeaconID_t`, `SiteId_t`, `RTime32` (Unix-epoch-ish 32-bit timestamp), and `SteamAPICall_t` (handle to a deferred async API call whose result later arrives through `CallbackDispatcher`).

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): primitive-backed structs with literal `Invalid` sentinels and explicit conversions; `SteamAPICall_t` is the special coroutine-ish token checked via `IsCallComplete` in the hand-written layer.

## Flow
Created as return values of flat API calls (any interface), passed to comparison/auth/etc. calls, and — for `SteamAPICall_t` — awaited indirectly by polling `Steam.RunCallbacks()` from the editor's message pump.

## Integration
Referenced throughout `autogen/isteam*.cs` and `SteamCallbacks.cs`; upstream consumers include `Utility/SteamworksUGC` (app IDs) and the callback dispatch infrastructure; see `types/codemap.md` for the common generated-handle template. Vendored — do not restyle.
