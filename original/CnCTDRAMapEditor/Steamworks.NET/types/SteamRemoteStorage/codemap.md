# CnCTDRAMapEditor/Steamworks.NET/types/SteamRemoteStorage/

## Responsibility
Autogenerated value types for the Remote Storage / published-file API: `PublishedFileId_t` (the Workshop item ID — central to the editor's publish flow, with `Invalid` sentinel `0xffffffff` checked by `Dialogs/SteamDialog` to detect an unpublished map), `PublishedFileUpdateHandle_t` (older item-update token), `UGCHandle_t` (handle to a cloud file attached to a published item, e.g. its preview), and `UGCFileWriteStreamHandle_t` (handle for streamed cloud-file writes).

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): primitive-backed structs (`uint`/`ulong`) with `Invalid` sentinels, equality/comparison operators, and explicit conversions; one struct per file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
Publish/update operations on `ISteamUGC`/`ISteamRemoteStorage` produce and consume these handles; download/preview access routes through `UGCHandle_t`, cloud streaming through `UGCFileWriteStreamHandle_t`.

## Integration
Consumed by `autogen/isteamremotestorage.cs`/`isteamugc.cs`, `Utility/SteamworksUGC.cs` and `Dialogs/SteamDialog` (visibility/`PublishedFileId` bookkeeping in `Map.SteamSection`); see `types/codemap.md` for the common generated-handle template. Vendored — do not restyle.
