# CnCTDRAMapEditor/Steamworks.NET/types/SteamInventory/

## Responsibility
Autogenerated value types for the Steam Inventory Service: `SteamInventoryResult_t` (async result handle for an inventory operation), `SteamInventoryUpdateHandle_t` (version token for a definition/update stream), `SteamItemDef_t` (item definition ID from the item schema), and `SteamItemInstanceID_t` (a concrete item instance owned by a user).

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): primitive-backed structs (`uint`/`ulong`) with `Invalid` sentinels, equality/comparison operators, explicit conversions; one struct per file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
Inventory calls (`GetAllItems`, `TriggerItemDrop`, …) return a `SteamInventoryResult_t`; completion is dispatched as `SteamInventoryResultReady_t`, and the result's item descriptors pair `SteamItemDef_t` with `SteamItemInstanceID_t`/quantities. Update handles track schema revision for polling.

## Integration
Consumed by `autogen/isteaminventory.cs` and the gameserver stats/inventory classes; see `types/codemap.md` for the common generated-handle template. Unused by the editor — vendored for SDK completeness; do not restyle.
