# CnCTDRAMapEditor/Steamworks.NET/types/SteamUnifiedMessages/

## Responsibility
Autogenerated handle struct for the Unified Messages (RPC) API: `ClientUnifiedMessageHandle`, the opaque token for one in-flight protobuf RPC issued through `ISteamUnifiedMessages` to a Steam service method.

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): `ulong`-backed struct with `Invalid` sentinel, equality/comparison operators, and explicit conversions; single file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
`SendMethod`/`SendNotification` return the handle; the RPC response arrives as `UnifiedMessagesCallResult`-style data addressed by that handle, then it is released. The interface was deprecated in later SDKs and never used by this editor — its group exists only because the generator emits one folder per header.

## Integration
Consumed by `autogen/isteamunifiedmessages.cs`; see `types/codemap.md` for the common generated-handle template. Vendored — do not restyle.
