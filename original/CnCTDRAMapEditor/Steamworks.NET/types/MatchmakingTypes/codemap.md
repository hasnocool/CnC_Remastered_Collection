# CnCTDRAMapEditor/Steamworks.NET/types/MatchmakingTypes/

## Responsibility
Autogenerated value types for the matchmaking/server-browsing interfaces: `servernetadr_t` (network address of a game server — IP + port + connection string helpers) and `gameserveritem_t` (one row of a server browser: name, map, players, ping, game/app data). Both are generated from the `steam_api` matchmaking headers per the Steamworks.NET build (© 2013–2019 Riley Labrecque, MIT); nothing here is hand-written.

## Design
Plain generated structs with SDK field names and light parsing/formatting helpers retained from the flat headers (`servernetadr_t` carries its own IP/port accessors; `gameserveritem_t` wraps query data returned by `ISteamMatchmaking` server list requests).

## Flow
`ISteamMatchmakingServers` fills `gameserveritem_t` records for each server in an `HServerListRequest`; `servernetadr_t` identifies the server on each item and can mint the `connect` string. Editor code (Workshop flows) does not consume these directly today.

## Integration
Used by `autogen/isteammatchmaking.cs` and the server-list APIs; see `types/codemap.md` for the common generated-handle template. Vendored — do not restyle.
