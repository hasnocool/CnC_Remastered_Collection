# CnCTDRAMapEditor/Steamworks.NET/types/SteamController/

## Responsibility
Autogenerated handle structs for the legacy (pre-"Steam Input") controller API: `ControllerHandle_t` (a physical/registered controller), plus `ControllerActionSetHandle_t`, `ControllerAnalogActionHandle_t`, and `ControllerDigitalActionHandle_t` — opaque tokens for action sets and their analog/digital actions declared in controller config profiles.

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): primitive-backed (`ulong`) structs with `Invalid` sentinel, `IEquatable`/`IComparable`, explicit conversions; one struct per file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
`ISteamController` resolves named action sets/actions from the controller action manifest into these handles once at startup, then per-frame `GetControllerState`/action-state calls pass the cached handles back in; there are no events.

## Integration
Consumed by `autogen/isteamcontroller.cs` and `NativeMethods.cs`; see `types/codemap.md` for the common generated-handle template. Editor code currently does not use controllers — vendored for SDK completeness; do not restyle.
