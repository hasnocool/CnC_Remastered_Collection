# CnCTDRAMapEditor/Steamworks.NET/types/SteamMatchmaking/

## Responsibility
Autogenerated request-handle structs for the matchmaking/lobby/server-list API: `HServerListRequest` (token for an in-progress game-server list query — passed to `ISteamMatchmakingServers` while enumerating `gameserveritem_t` records) and `HServerQuery` (token for a single follow-up rules/ping/player query against one server).

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): `uint`-backed structs with `Invalid` sentinel, equality/comparison operators, and explicit conversions; one struct per file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
`ISteamMatchmakingServers.RequestInternetServerList` etc. return an `HServerListRequest`; per-item details come through the `ISteamMatchmakingResponses` implementation (`Steamworks.NET/ISteamMatchmakingResponses.cs`) until the request is completed and released with a matching `Cancel`/`ReleaseRequest` call.

## Integration
Consumed by `autogen/isteammatchmaking.cs` together with `types/MatchmakingTypes/`; see `types/codemap.md` for the common generated-handle template. Vendored — do not restyle.
