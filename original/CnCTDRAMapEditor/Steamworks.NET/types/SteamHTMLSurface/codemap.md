# CnCTDRAMapEditor/Steamworks.NET/types/SteamHTMLSurface/

## Responsibility
Autogenerated handle struct for the in-client web surface API: `HHTMLBrowser`, the opaque token for one HTML surface (an embedded Chromium view inside the Steam client overlay/browser window).

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): `uint`-backed struct with `Invalid` sentinel, equality/comparison operators, explicit conversions; single file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
`ISteamHTMLSurface.CreateBrowser` returns a handle; every subsequent DOM/paint/keyboard call on that surface passes the token back; destruction on `RemoveBrowser`.

## Integration
Consumed by `autogen/isteamhtmlsurface.cs`; see `types/codemap.md` for the common generated-handle template. Unused by the map editor — vendored for SDK completeness; do not restyle.
