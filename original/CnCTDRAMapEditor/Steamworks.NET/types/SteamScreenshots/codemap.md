# CnCTDRAMapEditor/Steamworks.NET/types/SteamScreenshots/

## Responsibility
Autogenerated handle struct for the screenshot API: `ScreenshotHandle`, the opaque token returned by `ISteamScreenshots.AddScreenshotToLibrary`/`WriteScreenshot` identifying one screenshot registered with the Steam client.

## Design
Standard generated pattern (© 2013–2019 Riley Labrecque, MIT): `uint`-backed struct with `Invalid` sentinel, equality/comparison operators, and explicit conversions; single file, `#if !DISABLESTEAMWORKS` guarded.

## Flow
Screenshot-taking calls return the handle; subsequent tagging (`TagScreenshot`/location/user attribution) and status callbacks (`ScreenshotReady_t`) reference it. `Dialogs/SteamDialog` instead saves its workshop preview directly as a PNG file, so this API is not on the publish path today.

## Integration
Consumed by `autogen/isteamscreenshots.cs`; see `types/codemap.md` for the common generated-handle template. Unused by the editor — vendored for SDK completeness; do not restyle.
