# CnCTDRAMapEditor/Steamworks.NET/types/SteamClientPublic/

## Responsibility
Autogenerated identity types from the SDK's public client headers (`steamtypes`/`steamclientpublic.h` heritage): `CSteamID` (the 64-bit Steam account/session identifier with account-type/universe bit-field accessors — the universal player identity), `CGameID` (compactly encoded app/mod identity for in-game context), and `HAuthTicket` (handle to an issued auth session ticket).

## Design
Larger than the average generated handle: `CSteamID` reproduces the SDK's bit-packed layout (instance, account type, universe, account number) with full constructors and accessors; all keep the standard generated equality/conversion pattern (© 2013–2019 Riley Labrecque, MIT), one struct per file.

## Flow
`Steam.Init` establishes the local user's `CSteamID`; Workshop flows use it implicitly through the API, `HAuthTicket` values are returned by session-ticket calls and later validated/invalidated. Editor code mostly passes them opaquely.

## Integration
Consumed by `autogen/isteamclient.cs`, `isteamuser.cs`-family signatures and by callback structs; see `types/codemap.md` for the common generated type template. Vendored — do not restyle.
